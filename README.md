# Бухучёт

Локальная консольная программа для обработки банковских Excel-файлов, распределения типов операций и исполнителей, подготовки премий и накопления операций по сотрудникам.

## Готовая версия для Windows 7

Готовые архивы публикуются в разделе **Releases** репозитория. Для рабочего компьютера нужна версия `Buhuchet-Windows7-x64.zip`.

После скачивания:

1. полностью распакуйте архив;
2. положите исходные Excel-файлы рядом с `Buhuchet.exe`;
3. запускайте `START_BUHUCHET.bat`;
4. не удаляйте создаваемые программой папки годов и месяцев.

Python и PyCharm на рабочем компьютере не нужны.

## Обновление

Скачайте архив нового релиза и замените программные файлы. Перед обновлением рекомендуется скопировать папки годов в резервное место. Рабочие `.xls`, `.xlsx`, `.csv` и папки годов исключены из Git и не должны публиковаться.

## Запуск из исходного кода

Для Windows 7 используется Python 3.8 x64:

```bat
py -3.8 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements-win7.txt
python buhuchet.py
```

## Создание релиза

Автоматическая сборка запускается для тега вида `v1.0.0`:

```bash
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions соберёт архив и добавит его в Releases. Сборка использует Python 3.8 и старые зафиксированные библиотеки для максимально возможной совместимости с Windows 7. Фактическую совместимость необходимо проверять на целевом компьютере.
