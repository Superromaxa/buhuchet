# Бухучёт

Локальная консольная программа для обработки банковских Excel-файлов, распределения типов операций и исполнителей, подготовки премий и накопления операций по сотрудникам.

## Готовая версия для Windows 11 x64

Готовые архивы публикуются в разделе **Releases** репозитория. Для рабочего компьютера нужна версия `Buhuchet-Windows11-x64.zip`.

После скачивания:

1. полностью распакуйте архив;
2. положите исходные Excel-файлы рядом с `Buhuchet.exe`;
3. запускайте `START_BUHUCHET.bat`;
4. не удаляйте создаваемые программой папки годов и месяцев.

Папка `_internal` должна оставаться рядом с `Buhuchet.exe`.

Python и PyCharm на рабочем компьютере не нужны.

## Обновление

Закройте программу и распакуйте новый архив в отдельную папку. Скопируйте туда свои папки годов, рабочие Excel-файлы и папку «Старые таблицы», если используете её. Запускайте программу из новой папки, а старую сохраните как резервную копию. Рабочие `.xls`, `.xlsx`, `.csv` и папки годов исключены из Git и не должны публиковаться.

## Запуск из исходного кода

Используется Python 3.12 x64:

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements-windows.txt
python buhuchet.py
```

## Создание релиза

Обновите `VERSION` (например, `v1.3.0`) и `RELEASE_NOTES.md`, затем отправьте изменения в `main`. Изменение `VERSION` или сценария сборки запускает тесты, сборку Windows x64 и проверку готового `.exe` на синтетической выписке. Только после успешных проверок GitHub Actions создаёт тег на проверенном коммите и публикует релиз с архивом и SHA-256.

Для локальной проверки:

```bat
python -m unittest discover -s tests -v
```

Ручной запуск workflow создаёт тестовый архив без публикации. Также поддерживается отправка тега, совпадающего с `VERSION`. Не публикуйте один номер версии повторно.

Сборка выполняется на Windows Server 2022 и предназначена для Windows 11 x64. Windows 7 больше не является целевой системой; старая сборка доступна в релизе v1.2.0.
