КРАТКАЯ ПРОВЕРКА ПРОГРАММЫ

При запуске программа спрашивает год и месяц работы.
Потом она показывает таблицы из папок этого года и месяца.
Можно выбрать нужные таблицы для загрузки.

Обычный порядок работы: 1, потом 2, потом 3.


1 — ДОБАВИТЬ ТИП ОПЕРАЦИИ

Выберите банковскую таблицу.
Программа определит тип каждой операции: товар, пришло, налог и другие.

Если тип не определился, программа покажет строку и попросит выбрать тип вручную.

Результат: файл с окончанием _с_типами.xlsx.

Если все строки распознаны, пустой файл _нераспознанные.xlsx не создаётся.


2 — ДОБАВИТЬ ИТОГОВУЮ СУММУ

Выберите таблицу с типами операций.
Программа добавит столбец «Итоговая сумма».

Обычно сумма берётся из Дт или Кт.
Для возмещения по договору к сумме добавляются комиссия и НДС.
Если комиссия или НДС не найдены, программа попросит ввести число вручную.

Результат: таблица с добавленной итоговой суммой.


3 — ДОБАВИТЬ ИСПОЛНИТЕЛЯ

Сначала выберите вид таблиц исполнителей:

1 — подготовленные таблицы;
2 — старые таблицы.

Для подготовленных таблиц программа попросит файлы конкурса и б/т
для Алексея, Владимира и Дмитрия.

Для старых таблиц программа возьмёт файлы из папки «Старые таблицы»
рядом с программой.

Потом выберите основную таблицу с итоговыми суммами.

Программа сначала ищет одну точно такую же сумму.
Если не нашла, проверяет суммы из двух строк, потом из трёх строк.

В результат добавляются исполнитель, номер, наименование, фирма,
конкурс, страховка и затраты.

Страховка и затраты копируются из таблиц исполнителей.
Если значение не перенеслось, его нужно заполнить вручную.

Результат: файл с окончанием _с_исполнителями.xlsx.


4 — СОБРАТЬ ОПЕРАЦИИ ПО ИСПОЛНИТЕЛЮ

Выберите одну или несколько таблиц через запятую.
Например: 1, 3, 5

Потом выберите человека.
Программа соберёт его операции из всех выбранных таблиц.

Если в папке года уже есть файл человека, например Алексей_2026.xlsx,
программа предложит дописать новые строки в конец.

Если файла нет, можно создать новый или указать старый файл.


5 — СОСТАВЛЕНИЕ ПРЕМИЙ

Выберите одну или несколько таблиц с исполнителями через запятую.

Программа соберёт все операции с типом «товар» или «пришло».

Будут созданы два файла:

премия_месяц.xlsx — общая таблица операций;
премии_сотрудников.xlsx — готовые суммы премий.

Для б/т премия равна 3 процентам от итоговой суммы.

Для конкурса премия считается так:
(итоговая сумма минус затраты минус страховка) умножить на 15 процентов.

Премия считается для Алексея, Владимира и Дмитрия.
Андрей в расчёт премии не входит.


6 — СФОРМИРОВАТЬ ИТОГОВУЮ ТАБЛИЦУ

Выберите одну или несколько готовых таблиц с исполнителями через запятую.

Программа сформирует строки: дата, фирма, тип, подтип и сумма.
Название фирмы берётся из имени выбранного файла.

Если не заполнены исполнители или затраты, программа сообщит об этом
и вернётся в главное меню. Сначала исправьте указанные строки.

Если операция не подошла ни под одно правило, она попадёт в отдельный
файл _неучтенные.xlsx для ручной проверки.


7 — ТАБЛИЦА ВСЕХ ОПЕРАЦИЙ

Есть два варианта:

1 — составить таблицу автоматически из выбранных банковских таблиц;
2 — добавить одну запись вручную.

В автоматическом режиме программа записывает дату, фирму, контрагента,
пришло или ушло, тип операции, наименование, сумму и комментарий.

Перевод между своими фирмами записывается двумя строками: у одной фирмы
деньги ушли, у другой пришли. Если выбраны выписки обеих фирм, программа
не должна создавать четыре одинаковые строки.

В ручном режиме программа по очереди попросит заполнить каждое поле.
Можно вводить свои типы операций, например «долг» или «личное».

Результат: таблица_всех_операций.xlsx в папке рабочего месяца.


8 — ДОПОЛНИТЕЛЬНЫЕ ВОЗМОЖНОСТИ

Здесь можно:

1 — переименовать загруженный файл;
2 — загрузить дополнительные таблицы, которые не выбрали при запуске.


-1 — ЗАВЕРШИТЬ РАБОТУ

Перед закрытием программа сохраняет таблицы текущей работы.
Дождитесь сообщения «Работа программы завершена».
