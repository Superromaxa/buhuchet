Версия для **Windows 11 x64**. Скачайте **Buhuchet-Windows11-x64.zip**, полностью распакуйте архив и запускайте **START_BUHUCHET.bat**. Python и Excel для работы программы устанавливать не нужно.

## Изменения

- Новые таблицы исполнителей сохраняются в памяти до конца сессии. После загрузки доступен пункт «подгруженные новые таблицы».
- Сначала сопоставляются все одиночные точные суммы; при нескольких совпадениях выбирается первое неиспользованное. Затем проверяются группы по номеру и дате внутри одного файла: пары, тройки и суммы целых групп из четырёх и более строк.
- В годовых таблицах сотрудников добавлен последний столбец «отслежено» со значением «нет». При дополнении ранее заполненные отметки сохраняются.
- Штрафы по Кт отражаются в «Прибыль / Штраф», по Дт — в «Убыток / Штраф».
- Возврат средств по депозитному договору распознаётся как «депозит возврат».
- Сокращённая оплата за техобслуживание для «Океан Сервис» распознаётся как «ПО».
- Уточнены правила для обеспечений, комиссий, налогов, снятий и переводов между своими компаниями.
- Итоговую таблицу можно создать на год или дополнить уже загруженную.
- Сборка переведена на Python 3.12 x64 и обновлённые библиотеки. Перед публикацией выполняются тесты и проверка обработки Excel собранной программой.

## Обновление с предыдущей версии

Закройте программу, распакуйте архив в новую папку и скопируйте туда свои папки годов, рабочие Excel-файлы и папку «Старые таблицы», если используете её. Запускайте программу из новой папки. Папка `_internal` из архива должна оставаться рядом с `Buhuchet.exe`. Старую папку сохраните как резервную копию.

Этот архив предназначен для Windows 11 x64; для Windows 7 оставлена предыдущая версия v1.2.0.
