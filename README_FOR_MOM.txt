БУХУЧЕТ — ЗАПУСК НА WINDOWS 11 x64

1. Распакуйте архив полностью в отдельную папку, например:
   C:\Бухучет

2. Не запускайте программу прямо из ZIP-архива.

3. Положите исходные банковские файлы в папку рядом с Buhuchet.exe.

4. Запускайте START_BUHUCHET.bat двойным щелчком.

5. При первом запуске Windows может показать предупреждение. Выберите
   разрешение запуска, только если архив был скачан из официального
   репозитория Superromaxa/buhuchet.

6. Папки годов и месяцев создаются рядом с программой автоматически.
   Не удаляйте их при обновлении программы.

7. Папка _internal должна оставаться рядом с Buhuchet.exe.
   Python отдельно устанавливать не нужно.

ОБНОВЛЕНИЕ

1. Скачайте новый архив Buhuchet-Windows11-x64.zip из раздела Releases.
2. Закройте программу.
3. Полностью распакуйте новую версию в отдельную папку.
4. Скопируйте в неё папки годов (например, 2026), рабочие Excel-файлы
   и папку «Старые таблицы», если используете её.
5. Запускайте START_BUHUCHET.bat из новой папки.
6. Старую папку сохраните как резервную копию.
